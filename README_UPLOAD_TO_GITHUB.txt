GitHub upload instructions:

1. Unzip this package on your computer.
2. Open your draft branch in GitHub, for example: draft/swedavia-smartvel-solution-hub.
3. Upload BOTH:
   - index.html
   - the entire assets folder
4. Do NOT upload the .zip file itself.
5. Keep the folder structure exactly as provided:
   index.html
   assets/images/...
   assets/videos/...
   assets/docs/...
6. Commit the upload and wait for the Vercel Preview Deployment.
7. Test the preview:
   - hero imagery loads
   - videos play
   - Explore & Go / Trip Planner / EntryDocs sections render
   - PDF download links work
   - mobile layout works

If GitHub rejects a file, it is normally because it is too large. This version uses a compressed Swedavia mock-up PDF and keeps each file below typical GitHub browser-upload limits.
