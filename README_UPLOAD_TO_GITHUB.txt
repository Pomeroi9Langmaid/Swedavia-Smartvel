GitHub upload instructions - flat version:

1. Unzip this package on your computer.
2. Open the unzipped folder.
3. Select all files inside the folder.
4. In GitHub, open the correct draft branch.
5. Click Add file > Upload files.
6. Drag all selected files into GitHub.
7. Do not upload the ZIP itself.
8. Commit the upload and wait for the Vercel Preview Deployment.
9. Test the preview:
   - index.html opens correctly
   - hero imagery/videos load
   - Explore & Go / Trip Planner / EntryDocs sections render
   - external demo links open
   - PDF download links work
   - mobile layout works

This package has no folders. All images, videos and PDFs sit beside index.html.
